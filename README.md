# Pair Tracker demo

A demo copy of the page from my option-pair tracker: it follows NVDA put/call pairs (strangles and straddles)
and works out a sell price for each leg from the pair's value with the stock at the midpoint of the strikes.

Open it here: https://dabosspanda99.github.io/pair-tracker-demo/

Everything on it is made-up practice data, frozen at one moment. It isn't connected to any brokerage, and its
buttons don't send anything. Hover a leg's midpoint value to see how it is calculated (Black-Scholes, step by step).
